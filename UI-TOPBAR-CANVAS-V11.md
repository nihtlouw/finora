# Finora UI v11 — Topbar & Canvas Integration

- Topbar now uses the same green-teal translucent language as the page canvas.
- Search and notification controls use smoke surfaces rather than pure white.
- Body gradient uses rgba(6,74,69,...) as the primary top canvas identity and fades gradually downward.
- Sidebar and main content retain a clear layer separation without introducing a white band at the top.
- Active navigation and modal/header surfaces use smoke-white surfaces.

This is a CSS/UI-only update; no database or schema changes.

# Finora Canonical Workflow v1

## Commercial
Client/Vendor → Proposal → WON/LOST → Customer PO → VERIFIED → Project

## Billing & collection
Project → Billing Schedule → READY → Invoice → Payment → Cashflow

Billing/Payment schedules are plans. Invoice/Payment/Cashflow are actual financial records.

## Cost control
Project Expense → APPROVED → Expense Allocation → Project Cost → Profitability

## Guard rules
- Proposal direct conversion to Invoice is retired.
- Project invoice must originate from a READY Billing Milestone.
- Payment actuals belong to invoices, not payment schedules.
- Gross profitability uses PO/contract revenue basis and approved project cost.

## Navigation IA
Workspace → Commercial → Billing & Collection → Cost & Treasury → Control & Insights → System

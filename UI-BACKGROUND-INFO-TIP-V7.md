# Finora UI v7

- Page background: Finora-green tint at the top fading to the existing soft neutral base lower down.
- Cards remain white so content blocks remain visually dominant.
- Form controls use a clearer translucent gray-green surface to make input areas obvious.
- Contextual help popovers render through a body-level portal, avoiding clipping by cards, overflow containers, and other stacking contexts.
- Help popovers clamp to the viewport and automatically choose above/below placement based on available space.
- Help popovers reposition on resize and scroll, and close with Escape or outside click.
